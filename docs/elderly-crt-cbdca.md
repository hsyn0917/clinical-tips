# 高齢者局所進行NSCLC：daily CBDCA + TRT 投与基準

出典：JCOG0301試験（Atagi S, et al. *J Clin Oncol.* 2012）

---

## 対象レジメン

**カルボプラチン 30 mg/m²/day**（放射線照射1時間前）＋ 胸部放射線療法（同時化学放射線療法）

---

## 開始基準（適格基準）

| 項目 | 基準 |
|------|------|
| 疾患 | 細胞診または組織診で確認されたNSCLC |
| 年齢 | **71歳以上** |
| 病期 | 切除不能III期（IIIA・IIIB） |
| 除外病期 | T3N1M0、対側肺門転移、全肺無気肺、悪性胸水・心嚢液あり |
| 測定可能病変 | あり |
| 前治療 | 化学療法・放射線療法なし |
| PS | ECOG 0〜2 |
| PaO₂ | **≥ 70 mmHg** |
| WBC | **≥ 4,000/μL** |
| Hb | **≥ 9.5 g/dL** |
| 血小板 | **≥ 10万/μL** |
| T-Bil | **≤ 1.5 mg/dL** |
| AST/ALT | 施設基準上限の2倍以下 |
| Cr | 施設基準上限以下 |
| 同意 | 文書同意あり |

### シスプラチン不適の判断基準（本試験の組み入れ理由）

| 年齢 | 条件 |
|------|------|
| **75歳以上** | 原則としてシスプラチン不適 |
| **71〜74歳** | 併存疾患・ECOG PS 2・聴力障害のいずれかあり |

### 主な除外基準

- 活動性感染症
- 間質性肺炎・活動性肺線維症
- 慢性閉塞性肺疾患
- コントロール不良の心疾患
- 活動性の重複癌 / 異時性癌（過去5年以内）

---

## 治療休止基準

### CBDCA 休止基準

| 項目 | 休止基準 |
|------|---------|
| WBC | **< 2,000/μL** |
| 好中球数 | **< 1,000/μL** |
| 血小板 | **< 5万/μL** |

### 放射線治療 休止基準

| 項目 | 休止基準 |
|------|---------|
| 呼吸困難・肺臓炎 | **Grade 2以上** |
| PaO₂低下 | ベースラインから **≥ 10 mmHg** 低下かつ **< 70 mmHg** |
| 発熱 | **≥ 38℃** |
| WBC低下 | **< 1,000/μL** |
| 好中球減少 | **< 500/μL** |
| 血小板減少 | **≤ 2.5万/μL** |
| 放射線食道炎 | **Grade 3以上** |

---

## 治療中止基準

### CBDCA 中止基準（休止後2週間経過しても改善なき場合）

| 項目 | 中止基準 |
|------|---------|
| WBC | **< 1,000/μL** |
| 好中球数 | **< 500/μL** |
| 血小板 | **< 2.5万/μL** |

### 放射線治療 中止基準

| 項目 | 中止基準 |
|------|---------|
| 肺臓炎 | 照射野外へ広がる **Grade 1以上**の肺臓炎 |
| 治療期間延長 | 治療開始から **9週超**（休止による延長） |

---

!!! note "最終判断は担当医の臨床判断に基づく"
