| 項目 | 内容 |

## 4. Grading：過敏症の重症度評価

適正使用ガイドではGrade分類はNCI-CTCAE ver. 4.03に準じるとされている。

| Grade | 臨床像の目安 | レットヴィモでの実務上の解釈 |
|---|---|---|
| Grade 1 | 軽度。一過性の皮疹、潮紅、薬剤熱など。介入不要又は軽微な介入で対応可能 | 発熱・皮疹が軽度でも、肝機能・血小板を確認する |
| Grade 2 | 中等度。薬物治療などの医学的介入を要する | 原則として過敏症疑いとして休薬を検討 |
| Grade 3 | 重度又は医学的に重要。入院又は入院期間延長を要する、自己管理ADL制限など | 休薬、全身ステロイド、再開するなら大幅減量から |
| Grade 4 | 生命を脅かす。緊急処置を要する | アナフィラキシー等の重篤な過敏症であれば中止、再投与しない |
| Grade 5 | 死亡 | 該当すれば死亡有害事象 |

CTCAEの一般原則では、Grade 3は「重症又は医学的に重要だが直ちに生命を脅かさない」、Grade 4は「生命を脅かす」、Grade 5は「死亡」と位置づけられる。

## 5. 対応方法

### 5.1 投与前

| 確認項目 | 対応 |
|---|---|
| 本剤成分に対するアナフィラキシー等の重篤な過敏症の既往 | 禁忌。投与しない |
| ICI前治療歴 | 高リスクとして説明・観察を強化 |
| ICI最終投与からの期間 | 6ヵ月未満、特に3ヵ月未満では過敏症に注意 |
| ベースライン検査 | 皮膚所見、体温、CBC、血小板、AST/ALT、ビリルビンを確認 |

本剤成分に対するアナフィラキシー等の重篤な過敏症既往は禁忌とされており、投与前チェックリストでも確認項目に含まれている。

### 5.2 発現時

| 状況 | 対応 |
|---|---|
| 過敏症を疑う発熱・皮疹 | レットヴィモを休薬 |
| 発熱・皮疹に加えALT/AST増加、血小板減少を伴う | 遅発性過敏症として扱う |
| Grade 1〜4の過敏症、ただしアナフィラキシー等の重篤な過敏症を除く | 回復まで休薬し、副腎皮質ステロイド全身投与を考慮 |
| アナフィラキシー等の重篤な過敏症 | 投与中止。再投与しない |

適正使用ガイドでは、Grade 1〜4の過敏症（アナフィラキシー等の重篤な過敏症を除く）の場合、回復するまで休薬し、副腎皮質ステロイド全身投与を考慮するとされている。

### 5.3 再開時

| 手順 | 内容 |
|---|---|
| 1 | 症状・検査値が回復するまで休薬 |
| 2 | 副腎皮質ステロイドを併用しながら再開 |
| 3 | 本剤は3段階減量して再開 |
| 4 | 再開後7日以上再発がなければ、1段階ずつ発現時の用量まで増量可 |
| 5 | 本剤増量後7日以上再発がなければ、副腎皮質ステロイドを漸減 |
| 6 | 再燃時は再休薬又は中止を検討 |

成人の通常用量160 mg 1日2回からの3段階減量は、40 mg 1日2回に相当する。適正使用ガイドでは、回復後に副腎皮質ステロイドを併用しながら3段階減量で再開し、7日以上再発がなければ1段階ずつ増量できるとされている。

## 6. 実務上の観察項目

| タイミング | 観察・検査 |
|---|---|
| 投与開始前 | 皮膚所見、体温、CBC、血小板、AST/ALT、ビリルビン |
| 投与開始後1〜2週 | 発熱、皮疹、掻痒、倦怠感、消化器症状、CBC、血小板、肝機能 |
| ICI前治療歴あり | 少なくとも開始後2週間は過敏症を意識して早期再診又は電話確認を検討 |
| 再開後 | 7日単位で再燃の有無を確認しながら段階的増量 |

## 7. 要点

| 項目 | 要点 |
|---|---|
| NSCLCでの頻度 | 全Grade 11.7%、Grade 3以上 3.9% |
| 日本人NSCLC | 全Grade 17.1%、Grade 3以上 11.4% |
| ICI前治療歴あり | 全Grade 18.2%、Grade 3以上 7.3% |
| ICIから3ヵ月未満 | 全Grade 27.3%、重篤例 10.6% |
| 典型像 | 投与開始後1〜2週の発熱・皮疹・ALT/AST増加・血小板減少 |
| 基本対応 | 休薬、全身ステロイド考慮、回復後に3段階減量で再開 |
| 再増量 | 7日以上再発なしを確認し、1段階ずつ増量 |
| 中止すべき状況 | アナフィラキシー等の重篤な過敏症 |
