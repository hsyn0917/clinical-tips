# S-1（エスワン）単剤療法 クイックリファレンス
**対象疾患：非小細胞肺癌（NSCLC）**
商品名：ティーエスワン®配合OD錠 T20 等

---

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| 分類 | 代謝拮抗薬（ピリミジン拮抗薬） |
| 作用機序 | 5-FUのプロドラッグであるテガフール（FT）に、ギメラシル（CDHP）・オテラシルカリウム（Oxo）を配合。消化器毒性を軽減しつつ血中5-FU濃度を増大し、腫瘍内5-FU濃度を維持する |
| 投与経路・タイミング | 経口。**朝・夕の食後**、1日2回（空腹時は抗腫瘍効果減弱のおそれ → 必ず食後） |
| 制吐療法 | 軽度リスク（LEC） |
| 血管外漏出対策 | 不要 |
| 位置づけ | NSCLCの二次療法以降の選択肢。EAST-LCでは、プラチナ製剤既治療の進行NSCLCにおいてdocetaxelに対するOS非劣性が示された |

**代謝・相互作用**
- FT：主にCYP2A6による肝代謝。CDHP：一部はCDHP硫酸抱合体に代謝、50%以上は未変化体で腎排泄。Oxo：胃酸で分解。
- ⚠ **フェニトイン・ワルファリンは効果増強リスクあり** → 併用時は注意。

**主な副作用**
貧血、白血球減少、食欲不振、悪心、下痢、口内炎、色素沈着、倦怠感 等

## 2. 用法・用量

### 2-1. 初回投与量（体表面積基準）

| 体表面積（BSA） | 1回量 | 1日量 |
|---|---|---|
| BSA < 1.25 m² | 40 mg/回 | 80 mg/日 |
| 1.25 m² ≦ BSA < 1.5 m² | 50 mg/回 | 100 mg/日 |
| 1.5 m² ≦ BSA | 60 mg/回 | 120 mg/日 |

### 2-2. 腎機能障害に基づく調整
> 腎機能障害患者ではギメラシルの腎排泄が著しく低下し、血中5-FU濃度が上昇 → 骨髄抑制が強く出る可能性。減量と慎重投与が必要。

| Ccr | 減量の参考値 |
|---|---|
| 80 mL/min 以上 | 初回基準量 |
| 60 〜 79 mL/min | 初回基準量でも投与可能（必要に応じて1段階減量） |
| 40 〜 59 mL/min | 1〜2段階減量を考慮、慎重投与 |
| 30 〜 39 mL/min | 2段階減量、慎重投与 |

⚠ **Ccr 30 mL/min 以下：原則禁忌。**
※初回基準量＝体表面積に基づく用量（2-1の表）。

### 2-3. 投与スケジュール
- **標準：28日間連日投与 → 14日間休薬**（＝42日 = 1クール）。
- 忍容性が問題となる場合は **14日投与 → 7日休薬** に変更可（後述の急性期毒性参照）。

## 3. 投与中の調整

### 3-1. 休薬・再開基準
> Day15〜29に休薬基準へ抵触する場合は、14日投与7日休薬へのスケジュール変更で忍容性が保てることがある。

| 有害事象 | 休薬基準 | 再開基準 |
|---|---|---|
| 好中球数 | 1,000/mm³ 未満 | 1,500/mm³ 以上 |
| 血小板数 | 75,000/mm³ 未満 | 100,000/mm³ 以上 |
| 感染 | 38度以上の発熱あり | 発熱なし |
| 下痢・口内炎・食欲不振 | グレード2以上 | グレード1以下に回復 |
| その他の非血液毒性 | グレード3以上 | グレード2以下に回復 |
| Ccr | 50 mL/min 未満 | 50 mL/min 以上 |

### 3-2. 減量基準（抵触したら次回投与量を減量）

| 有害事象 | 減量基準 |
|---|---|
| 好中球減少 | 500/mm³ 未満 |
| 血小板数 | 50,000/mm³ 未満 |
| 非血液毒性 | グレード3以上 |
| 腎機能障害 | Ccrに応じて投与量を減量（3-4参照） |

### 3-3. 用量レベル（減量段階）
> 減量基準に応じて適宜減量を検討。スケジュール変更で対応できる場合もある。

| 投与開始用量 | 1段階減量 | 2段階減量 | 3段階減量 |
|---|---|---|---|
| 120 mg/日 | 100 mg/日 | 80 mg/日 | 治療中止を考慮 |
| 100 mg/日 | 80 mg/日 | 治療中止を考慮 | ― |
| 80 mg/日 | 治療中止を考慮 | ― | ― |

## 4. 副作用マネジメント

### 4-1. 急性期毒性
一般に軽度。下記により減量やスケジュール変更（14日投与7日休薬）を要することがある。
**目安：投与開始14日以内の発現 → 減量／14日以後の発現 → スケジュール変更を検討。**

- **骨髄抑制**：点滴抗癌剤に比べ最下点（nadir）が遅く遷延しやすい。次コース開始基準に満たないこともあり、スケジュール変更・減量で対応。
- **消化器毒性**：食思不振・下痢など。遷延する場合あり。骨髄抑制と同様にスケジュール変更・減量で対応、重度なら投与中止も。

### 4-2. 晩期毒性
- **色素沈着**：投与開始後2〜3週目より発現。爪周囲・四肢の先端など日光に当たりやすい部位に起こる。日焼け止めの使用、過度な日光曝露を避ける指導を行う。

| 投与スケジュール | 28日投与・14日休薬 | 28日投与・14日休薬 | 28日投与・14日休薬 | 14日投与・7日休薬 |

### 5-2. EAST-LC試験（第Ⅲ相）

プラチナ製剤既治療の進行NSCLCを対象に、S-1単剤とdocetaxelを比較した東アジア多施設共同ランダム化第Ⅲ相試験。主要評価項目はOSで、非劣性マージンはHR 1.2。

| 項目 | S-1 | Docetaxel | 解釈 |
|---|---:|---:|---|
| 対象 | 577例 | 577例 | 二次・三次療法として実施 |
| OS中央値 | 12.75カ月 | 12.52カ月 | HR 0.945（95%CI 0.833-1.073）で非劣性達成 |
| PFS | - | - | HR 1.033（95%CI 0.913-1.168）で有意差なし |
| 奏効割合 | 8.3% | 9.9% | ほぼ同等 |
| QOL | 良好 | - | EORTC QLQ-C30 global health statusでS-1が良好 |
| 主な毒性 | 食欲低下、悪心、下痢 | 好中球減少、白血球減少、脱毛 | 経口薬だが消化器毒性に注意。骨髄抑制・脱毛はdocetaxelで多い |

日本人サブグループ（724例）でも、OS中央値はS-1 13.4カ月、docetaxel 12.6カ月、PFS中央値は2.9カ月、3.0カ月、奏効割合は9.4%、10.3%で、全体集団と同様に有効性はほぼ同等であった。
