# AFOPの画像・病理所見：OP・DADとの違い

## 0. 最も重要なまとめ

AFOP、通常OP、DADの違いは、まず以下のように整理すると分かりやすい。

| 病態       | 主役となる病理像         | 見え方                  |
| -------- | ---------------- | -------------------- |
| **通常OP** | Masson body      | 肺胞腔・肺胞管内の線維芽細胞性プラグ   |
| **AFOP** | fibrin balls     | 肺胞腔内に球状・塊状のフィブリンがたまる |
| **DAD**  | hyaline membrane | 肺胞壁に沿って膜状の好酸性物質が付着する |

最も単純化すると、

* **OP：線維芽細胞性プラグ**
* **AFOP：肺胞腔内フィブリンボール**
* **DAD：肺胞壁に沿う硝子膜**

である。

AFOPは、単に「OPにフィブリンが少し多い」病変ではない。
**肺胞腔内フィブリン沈着が主役となる急性〜亜急性肺傷害パターン**である。

DADとの違いは、**硝子膜の有無とフィブリンの存在様式**で整理する。

* **DAD**：フィブリンを含む滲出物が、肺胞壁に沿って膜状に付着する
* **AFOP**：フィブリンが、肺胞腔内で球状・塊状に集積する

---

## 1. AFOPとは

**AFOP** は **acute fibrinous and organizing pneumonia** の略で、病理学的には以下を特徴とする。

* 肺胞腔内に目立つ **fibrin balls**
* 器質化肺炎様の変化
* 斑状分布
* DADで典型的な **硝子膜を欠く**
* 好酸球性肺炎でみられるような著明な好酸球浸潤を欠く

AFOPは、OPとDADの中間的・重複的にみえることがあるが、病理学的には、
**肺胞腔内fibrin ballsを主病変とする急性肺傷害パターン**として捉える。

---

## 2. AFOPの画像所見

AFOPに特異的な画像所見はない。典型的には以下を示す。

| 所見                   | AFOPでの特徴                         |
| -------------------- | -------------------------------- |
| consolidation        | 両側性、多発性、斑状。下葉優位、末梢優位、胸膜下優位のことが多い |
| ground-glass opacity | consolidationに伴う、または単独でみられる      |
| nodular opacity      | 結節状、腫瘤様陰影としてみえることがある             |
| pleural effusion     | 典型的ではないが、少量胸水を伴うことがある            |
| 臨床像                  | 抗菌薬不応の肺炎様陰影として認識されることがある         |

画像だけでAFOPを確定することは困難であり、診断には病理所見が重要である。

---

## 3. AFOPの病理所見

AFOPの中核は、**肺胞腔内のフィブリン塊**である。

| 病理所見                        | 内容                               |
| --------------------------- | -------------------------------- |
| intra-alveolar fibrin balls | 肺胞腔内にフィブリンが球状・塊状に集積する。AFOPの最重要所見 |
| organizing pneumonia        | 肺胞腔・肺胞管内に器質化変化を伴う                |
| patchy distribution         | 病変は斑状に分布する                       |
| hyaline membraneなし          | DADとの重要な鑑別点                      |
| 著明な好酸球浸潤なし                  | 好酸球性肺炎との鑑別点                      |
| II型肺胞上皮過形成                  | 反応性変化としてみられることがある                |
| 肺胞隔壁肥厚                      | 浮腫・炎症・線維化を伴うことがある                |

---

## 4. 硝子膜とは何か

**硝子膜**は、DAD、特にARDSや急性間質性肺炎の滲出期で典型的にみられる病理所見である。

HE染色では、**肺胞壁の内面に沿って付着する均一な好酸性の膜状物質**としてみえる。

| 項目 | 内容                                    |
| -- | ------------------------------------- |
| 位置 | 肺胞隔壁・肺胞壁に沿う                           |
| 形  | 膜状、帯状、線状                              |
| 色  | HEで均一なピンク色、好酸性                        |
| 構成 | フィブリン、血漿蛋白、壊死した肺胞上皮細胞・細胞残渣など          |
| 意味 | 肺胞上皮・毛細血管内皮障害により、血漿成分が肺胞腔へ漏出していることを示す |

重要なのは、硝子膜は**フィブリンを含むが、単なるフィブリン塊ではない**という点である。
血漿蛋白や壊死細胞成分を含む膜状滲出物である。

---

## 5. 硝子膜とAFOPのfibrin ballの違い

実務上は以下の理解でよい。

| 所見   | 硝子膜                    | AFOPのfibrin ball  |
| ---- | ---------------------- | ----------------- |
| 主な構成 | フィブリンを含む血漿蛋白＋壊死細胞成分    | 主にフィブリン           |
| 位置   | 肺胞壁に沿って付着              | 肺胞腔内に存在           |
| 形    | 膜状、線状、帯状               | 球状、塊状             |
| 代表病態 | DAD / ARDS             | AFOP              |
| 見え方  | 肺胞壁の輪郭をなぞるようにピンク色の膜がある | 肺胞腔内に丸いフィブリン塊が詰まる |

まとめると、

* **DAD**：フィブリンを含む滲出物が、肺胞壁に沿って膜状に付着する
* **AFOP**：フィブリンが、肺胞腔内で球状・塊状に集積する

という違いである。

---

## 6. 通常OPとの違い

通常のOP、すなわち organizing pneumonia では、主病変は **Masson body** である。

Masson bodyとは、肺胞腔、肺胞管、細気管支腔内に形成されるポリープ状の疎な線維芽細胞性肉芽組織である。

| 項目    | 通常OP                  | AFOP                        |
| ----- | --------------------- | --------------------------- |
| 主病変   | Masson body、線維芽細胞性プラグ | intra-alveolar fibrin balls |
| フィブリン | あっても副次的               | 診断の中心                       |
| 病変の性格 | 器質化肺炎                 | フィブリン優位の急性肺傷害＋器質化           |
| 肺構築   | 比較的保たれる               | 肺胞隔壁肥厚やII型肺胞上皮過形成を伴うことがある   |
| 臨床像   | 亜急性、ステロイド反応性良好なことが多い  | 急性重症型から亜急性型まで幅がある           |

要点：

**OPは「線維芽細胞性プラグが主役」**
**AFOPは「肺胞腔内フィブリン塊が主役」**

である。

---

## 7. DADとの違い

DADは **diffuse alveolar damage** の略で、ARDSや急性間質性肺炎の病理学的対応である。

DADでは、滲出期に**硝子膜形成**が典型的にみられる。

| 項目    | DAD                 | AFOP                 |
| ----- | ------------------- | -------------------- |
| 主病変   | 硝子膜形成、びまん性肺胞上皮・内皮傷害 | 肺胞腔内fibrin balls＋器質化 |
| 分布    | びまん性、比較的均一          | 斑状                   |
| 硝子膜   | 典型的に存在              | 原則として欠く              |
| フィブリン | 滲出物として存在し得る         | fibrin ballsとして目立つ   |
| 臨床像   | ARDS様の急性呼吸不全        | 急性重症型から亜急性型まで幅がある    |

要点：

**DADでは肺胞壁に沿う硝子膜が重要**
**AFOPでは肺胞腔内のfibrin ballsが重要**

である。

---

## 8. 鑑別の実務的ポイント

病理標本を見るときは、以下の順に確認すると整理しやすい。

| 見るポイント                   | 診断の方向                |
| ------------------------ | -------------------- |
| 肺胞腔内に球状・塊状の好酸性フィブリンが目立つか | AFOPを考える             |
| 肺胞壁に沿う膜状・線状の好酸性物質があるか    | DADの硝子膜を考える          |
| Masson body主体か           | 通常OPを考える             |
| 好酸球浸潤が著明か                | 好酸球性肺炎を考える           |
| 検体が小さいか                  | AFOPとDADの厳密な鑑別に限界がある |

---

## 9. 注意点

実際の標本では、急性肺傷害の時間相やサンプリングの影響により、AFOP様所見とDAD様所見が混在してみえることがある。

特に小さなTBLBやcryobiopsyでは、

* 硝子膜を見逃す
* fibrin ballsを部分的にしか評価できない
* DADの器質化期とAFOPの鑑別が難しい

という問題がある。

したがって、AFOPを診断する際には、単に「フィブリンがある」だけでなく、

* 肺胞腔内に球状・塊状のフィブリンが目立つか
* 典型的な硝子膜を欠くか
* Masson body主体の通常OPとは異なるか

を確認する必要がある。

---

## 10. 一文でまとめる

**AFOPは、肺胞腔内にfibrin ballsを形成するフィブリン優位の急性〜亜急性肺傷害パターンであり、通常OPとは主役がMasson bodyではなくフィブリン塊である点、DADとは肺胞壁に沿う硝子膜を欠く点で異なる。**
