# CBDCA + nab-PTX 投与基準（NSCLC・B法：毎週投与法）

出典：アブラキサン® 適正使用ガイド（大鵬薬品）、電子添文

---

## 投与スケジュール

| 薬剤 | 用量 | 投与日 | サイクル |
|------|------|--------|---------|
| nab-パクリタキセル（アブラキサン®） | **100 mg/m²**（30分点滴） | Day 1, 8, 15 | 3週毎 |
| カルボプラチン | **AUC 6** | Day 1 | 3週毎 |

---

## 開始基準（初回・各コース Day 1）

### 初回投与（Day 1）

| 項目 | 適正使用基準 |
|------|------------|
| PS | **ECOG 0〜1** |
| 好中球数 | **≥ 1,500/μL** |
| 血小板数 | **≥ 10万/μL** |
| Hb | **≥ 9.0 g/dL** |
| AST・ALT | **≤ ULN × 2.5倍**（肝転移・原疾患起因は5倍まで） |
| T-Bil | **≤ 1.5 mg/dL** |
| Cr | **≤ 1.5 mg/dL** |
| 心電図 | 臨床上問題となる異常所見なし |
| 末梢神経障害 | **≤ Grade 1** |

### 次コース開始基準（2コース目以降 Day 1）

| 項目 | 基準 |
|------|------|
| 好中球数 | **≥ 1,500/μL** |
| 血小板数 | **≥ 10万/μL** |
| Hb | **≥ 9.0 g/dL** |
| AST・ALT | **≤ ULN × 2.5倍**（肝転移・原疾患起因は5倍まで） |
| T-Bil | **≤ 1.5 mg/dL** |
| Cr | **≤ 1.5 mg/dL** |
| 末梢神経障害 | **≤ Grade 2**（Grade 2でも延期を考慮） |

---

## コース内投与基準（Day 8・Day 15）

| 項目 | 基準 |
|------|------|
| 好中球数 | **> 1,000/μL**（500〜1,000/μL は慎重投与） |
| 血小板数 | **≥ 5万/μL** |
| 末梢神経障害 | **≤ Grade 2**（Grade 2でも投与スキップを考慮） |

!!! note "投与スキップの流れ"
    - **Day 8** で基準未達 → Day 8 をスキップし、回復確認後 Day 15 を投与
    - **Day 15** で基準未達 → Day 15 をスキップし、回復確認後 次コースを開始

---

## 減量基準・再開基準

| 項目 | 減量基準 | 再開基準 | 減量時期 |
|------|---------|---------|---------|
| 好中球数 | **< 500/μL**、または < 1,500/μL のため **7日以上延期** | ≥ 1,500/μL | 次コース |
| 血小板数 | **< 5万/μL** | ≥ 10万/μL | 次コース |
| 発熱性好中球減少症 | 発現 | 回復 | 次コース |
| 末梢神経障害 | **≥ Grade 3** | ≤ Grade 1 | 次回投与 |
| 皮膚障害 | **≥ Grade 2** | — | 次回投与 |
| 粘膜炎・下痢 | **≥ Grade 3** | ≤ Grade 1 | 次回投与 |
| その他非血液毒性（脱毛除く） | **≥ Grade 3** | ≤ Grade 2 | 次回投与 |

### 減量の目安

| 段階 | nab-PTX | CBDCA |
|------|---------|-------|
| 通常投与量 | 100 mg/m² | AUC 6 |
| **1段階減量** | **75 mg/m²** | **AUC 4.5** |
| **2段階減量** | **50 mg/m²** | **AUC 3** |

!!! warning "注意"
    末梢神経障害は Grade 2 以下でも減量を考慮する。

## 注意を要する主な副作用

| 副作用 | 備考 |
|--------|------|
| 末梢神経障害 | 高頻度・用量制限毒性。投与期間が長くなるほど頻度上昇 |
| 骨髄抑制 | 用量制限毒性（DLT）。白血球が軽度でも著明な好中球減少あり、白血球分画の確認を |
| 感染症 | 好中球減少から重症感染症・死亡例あり |
| 間質性肺疾患 | 肺炎・肺臓炎・びまん性肺胞障害。初期症状（発熱・咳嗽・息切れ）に注意 |
| 脳神経麻痺 | 顔面神経麻痺、声帯麻痺等 |
| 黄斑浮腫 | 視力低下。遅れると長期視力障害のリスク。眼科コンサルト |

!!! note "最終判断は担当医の臨床判断に基づく"
