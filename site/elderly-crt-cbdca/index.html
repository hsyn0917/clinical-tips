    高齢者局所進行NSCLC：daily CBDCA + TRT 投与基準¶

    出典：JCOG0301試験（Atagi S, et al. Lancet Oncol. 2012）、JCOG0301プロトコール論文（Atagi S, et al. Jpn J Clin Oncol. 2005）

    対象レジメン¶

    カルボプラチン 30 mg/m²/day（放射線照射1時間前）＋ 胸部放射線療法（同時化学放射線療法）

    開始基準（適格基準）¶

    項目 基準
    疾患 細胞診または組織診で確認されたNSCLC
    年齢 71歳以上
    病期 切除不能III期（IIIA・IIIB）
    除外病期 T3N1M0、対側肺門転移、全肺無気肺、悪性胸水・心嚢液あり
    測定可能病変 あり
    前治療 化学療法・放射線療法なし
    PS ECOG 0〜2
    PaO₂ ≥ 70 mmHg
    WBC ≥ 4,000/μL
    Hb ≥ 9.5 g/dL
    血小板 ≥ 10万/μL
    T-Bil ≤ 1.5 mg/dL
    AST/ALT 施設基準上限の2倍以下
    Cr 施設基準上限以下
    同意 文書同意あり

    シスプラチン不適の判断基準（本試験の組み入れ理由）¶

    年齢 条件
    75歳以上 原則としてシスプラチン不適
    71〜74歳 併存疾患・ECOG PS 2・聴力障害のいずれかあり

    主な除外基準¶

    • 活動性感染症
    • 間質性肺炎・活動性肺線維症
    • 慢性閉塞性肺疾患
    • コントロール不良の心疾患
    • 活動性の重複癌 / 異時性癌（過去5年以内）

    コース内投与基準（JCOG0301プロトコール）¶

    CBDCA + TRT 併用期間¶

    以下の毒性を認める場合は、CBDCA・TRTともに休止する。休止後、それぞれの再開基準を満たした場合に CBDCA + TRT を再開する。

    JCOG0301プロトコール上、延期により治療期間が 63日を超える場合は治療中止とする。

    血液毒性¶

    休止基準 再開基準 備考
    白血球数 < 2,000/μL
    または 好中球数 < 1,000/μL
    または 血小板数 < 50,000/μL    		 休止後2週間以内に以下をすべて満たす
    白血球数 ≥ 2,000/μL
    好中球数 ≥ 1,000/μL
    血小板数 ≥ 50,000/μL    		 休止後2週間以内に再開基準を満たさない場合：
    白血球数 < 1,000/μL または 好中球数 < 500/μL または 血小板数 < 25,000/μL なら CBDCA + TRT中止
    白血球数 ≥ 1,000/μL かつ 好中球数 ≥ 500/μL かつ 血小板数 ≥ 25,000/μL なら TRTのみ継続

    白血球・好中球減少時には、可能な限り予防的な G-CSF は使用しない。

    非血液毒性¶

    毒性 休止基準 再開基準 備考
    肺毒性 呼吸困難 Grade 2以上への悪化
    または 肺臓炎 Grade 2以上    		 Grade 0へ回復 再燃する場合は治療中止
    肺毒性 肺臓炎 Grade 2以上で陰影が放射線照射野外へ及ぶ 治療中止し再開しない —
    食道炎 Grade 3以上 Grade 1以下へ回復 —
    発熱 38℃以上 37℃未満へ回復 —

    TRT 単独期間¶

    血液毒性¶

    休止基準 再開基準
    白血球数 < 1,000/μL
    または 好中球数 < 500/μL
    または 血小板数 < 25,000/μL    		 休止後2週間以内に以下をすべて満たす
    白血球数 ≥ 1,000/μL
    好中球数 ≥ 500/μL
    血小板数 ≥ 25,000/μL
    • 原則として、放射線照射中は G-CSF を投与しない。
    • G-CSF を使用した場合は、G-CSF 投与中止後3日後以降に白血球数 ≥ 1,000/μL および好中球数 ≥ 500/μL となり、治療再開可能と判断された場合に TRT を再開する。
    • 白血球数、好中球数、血小板数が休止基準に達していなくても、感染や肺炎、出血などの症状があれば臨床的に判断して治療を休止する。

    非血液毒性¶

    TRT 単独期間の非血液毒性は、上記「CBDCA + TRT 併用期間」の非血液毒性基準を参考に休止・再開を判断する。

    最終判断は担当医の臨床判断に基づく
